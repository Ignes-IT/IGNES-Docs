# IGNES

IGNES is a white-label VPN platform built around an API, a Telegram bot, and an AmneziaWG-compatible VPN server. This repository contains documentation for the platform and its current implementation.

## Repositories

- [IGNES-Core](https://github.com/Ignes-IT/IGNES-Core): API, PostgreSQL access, and VPN peer management.
- [IGNES-Telegram-Bot](https://github.com/Ignes-IT/IGNES-Telegram-Bot): Telegram interface and API client.
- [IGNES-Website](https://github.com/Ignes-IT/IGNES-Website): public landing page and plan display.
- [IGNES-Shared](https://github.com/Ignes-IT/IGNES-Shared): shared schemas, types, and brand configuration.
